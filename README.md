# 🚀 CodeAlpha Machine Learning Internship Projects

This repository contains the Machine Learning and Deep Learning projects developed as part of the **CodeAlpha Internship Program**.

The projects focus on solving real-world problems using Machine Learning, Deep Learning, Speech Processing, and Image Recognition techniques.

---

# 📌 Projects Included

## 💳 Task 1 — Credit Scoring Model

A Machine Learning project that predicts customer creditworthiness using financial and personal information.

### 🔹 Techniques Used

* Logistic Regression
* Random Forest
* XGBoost
* Feature Engineering
* Model Evaluation Metrics

---

## 🎤 Task 2 — Emotion Recognition from Speech

A Deep Learning project that recognizes human emotions from speech audio using speech signal processing techniques.

### 🔹 Techniques Used

* MFCC Feature Extraction
* Audio Augmentation
* Deep Neural Networks
* Batch Normalization
* Dropout

---

## ✍️ Task 3 — Handwritten Character Recognition

A CNN-based Deep Learning project that recognizes handwritten digits and alphabet characters using the MNIST and EMNIST datasets.

### 🔹 Techniques Used

* Convolutional Neural Networks (CNN)
* Data Augmentation
* Real-Time Image Prediction
* Confusion Matrix Analysis
* Overfitting Detection

---

## 🏥 Task 4 — Disease Prediction from Medical Data

A Machine Learning project that predicts diseases using structured medical datasets.

### 🔹 Techniques Used

* SVM
* Logistic Regression
* Random Forest
* XGBoost
* Medical Data Analysis
